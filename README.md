# 🗡️ 杀戮尖塔 DIY（Slay the Spire DIY）

> 一款在浏览器里就能玩的卡牌构筑 RPG——**爬塔、构筑、然后亲手定义这座塔**。

《杀戮尖塔 DIY》是致敬《杀戮尖塔》系列的网页版卡牌构筑游戏：纯前端、无需安装、打开浏览器即可游玩。它不只是"玩"，更是"造"——卡牌、怪物、遗物、事件全部可以 DIY，你的游戏由你定义。

## ✨ 核心亮点

- **5 位角色，5 套玩法体系**：铁甲战士的力量猛攻、静默猎手的毒刃与敏捷、储君的星辰之力、亡灵契约师的灵魂召唤与灾厄、故障机器人的宝珠矩阵——每位角色都有专属牌组、遗物与完全不同的资源机制。
- **488 张官方卡池**：内置《杀戮尖塔 2》EA 0.98.0 全部角色与无色卡，卡名 100% 中文化，效果结构化、可在游戏内精修。
- **完整 DIY 编辑器**：卡牌 / 怪物 / 遗物 / 事件 / 先古角色，可视化表单编辑、效果描述一键自动生成、导入导出 JSON——不改一行代码，就能做出自己的卡牌包。
- **数据随身携带**：你的全部 DIY 成果就是一个 `data/` 文件夹，拷贝或克隆即带走，换电脑无缝衔接。
- **丝滑的卡牌美术**：六种卡面材质（粗布 / 银灰 / 合金 / 金箔 / 闪卡 / 玻璃）、跟随鼠标的光影与 3D 倾斜、全息闪卡工艺——见过的都说像实体卡。
- **纯前端零依赖**：Vite + TypeScript + 原生 DOM，无后端、无游戏引擎，本地跑起来只要一条命令。

## 🎮 快速开始

```bash
git clone <仓库地址>
cd slay-the-spire-zanahorio
npm install
npm run dev
```

然后打开浏览器访问 **http://localhost:5173**。

在另一台电脑上初始化？完整图文教程见 [GETTING_STARTED.md](GETTING_STARTED.md)。
