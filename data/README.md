# data/ —— DIY 正式数据文件夹

把整个项目文件夹拷走，这里的 JSON 会跟着一起带走，DIY 数据就随身携带了。

## 文件说明

- `cards.json` —— 卡牌正式数据（`{ "id": { ... } }`，值为 `null` 表示删除内置卡牌）
- `enemies.json` —— 怪物正式数据
- `relics.json` —— 遗物正式数据
- `events.json` —— 事件正式数据
- `settings.json` —— 全局设置（初始生命/金币/抽牌/能量/起始牌组）
- `save.json` —— 自动存档（游戏进程自动读写）

## 读取优先级

1. 绑定的 data 文件夹（File System Access API，浏览器里点「绑定 data 文件夹」）
2. 本地服务器自动读取（`npm run dev` / 静态托管时的 `./data/*.json`）
3. 浏览器 localStorage 兜底（未绑定文件夹、直接双击打开时）

文件不存在时自动回退到游戏内置数据；编辑器里「写入正式数据」才会生成文件。

## 临时调整层

编辑器里的「临时微调」只写入浏览器 localStorage（调试覆盖），不污染本目录；
点「清空临时调整」即可一键还原。
