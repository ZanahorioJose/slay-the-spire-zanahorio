4 · 每种效果对应的 CSS 技术

  • 金属 / 金箔：多层 linear-gradient + inset box-shadow 做倒角与镜面高光
  • 闪卡箔面：conic-gradient 彩虹边框在圆角裁剪容器内旋转（overflow:hidden 防角部溢出）+ 扫光带
  • 3D 倾斜：perspective + rotateX/rotateY，鼠标位置换算成角度
  • 动态光照：CSS 变量 --lx/--ly 驱动 radial-gradient 高光中心
  • 玻璃：backdrop-filter 模糊 + 半透明渐变（背景光斑透出来）
  • 像素素材：canvas 画 16×16 底稿，整数倍放大 + image-rendering: pixelated； 未来可换成 assets/cards/ 实际卡图（见脚本顶部配置区）
  • 材质参考墙：下方 18 种 CSS 材质技术——拉丝/铬/碳纤（重复渐变）、 珍珠/油膜/大理石（conic + 混合模式）、岩浆/星云/霓虹（动画背景层）； 点任意卡片可切到主卡细调
  • 性能：transform/opacity 走 GPU 合成层；箔面旋转属重绘，看下方压测
