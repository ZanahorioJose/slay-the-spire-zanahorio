## 1. 风格定位：像素角色 + 3D 质感界面（HD-2D 混搭）

一句话：**角色和怪物是像素画，用 PNG 帧动画动起来；卡牌和 UI 是偏 3D 的材质化界面，用 CSS 模拟金属、皮革、玻璃等材质。**

这个组合参考「HD-2D」类游戏的观感——像素角色站在有纵深的场景里，界面是精致的高质感图层。两者的反差正是风格记忆点：

| 对象 | 风格 | 技术载体 |
| --- | --- | --- |
| 角色 / 怪物 | 像素画（低分辨率、透明底、有限调色板） | PNG Sprite Sheet 帧动画 |
| 卡牌上的动态素材 | 像素画（卡图窗口内的立绘/特效） | PNG 帧图 / 像素序列 |
| 卡牌本体（边框、底板、稀有度材质） | 3D 材质化（金属/皮革/箔面） | CSS 多层渐变 + 阴影 + 高光 |
| UI（按钮、面板、血条、能量、地图） | 3D 材质化（金属/皮革/玻璃/木材） | CSS 材质系统 |
| 背景 | 3D 纵深分层（远景雾/中景场景/近景站位） | CSS 分层 + 视差预留 |

设计原则：

1. **像素只出现在"画"里，材质只出现在"框"里**——角色、卡图、特效是像素；卡框、面板、按钮是材质。两者不混。
2. **材质为稀有度服务**——普通卡是粗布/皮革，稀有卡是金属，未来金卡是金箔、闪卡是动态箔面。材质分层一次做好，稀有度只是换材质贴层。
3. **所有动效尊重 `prefers-reduced-motion`**。
4. **像素必须整数倍放大**（`image-rendering: pixelated`），不允许非整数缩放导致糊边。
5. **文档与素材分工**：`docs/` 只放规范与讨论；实际素材（像素精灵表、卡图、UI 贴图、
   背景分层、材质包）统一放 `assets/`（见 §10）。

## 2. 角色 / 怪物：像素 Sprite 规范

播放状态机（待机↔受击↔攻击）见 `docs/animation-guide.md`；
本节为像素素材规格的唯一权威（分辨率 / 调色板 / 帧数 / 命名 / Prompt）：

### 2.1 画面规格

| 对象 | 基础分辨率 | 建议显示放大 | 备注 |
| --- | --- | --- | --- |
| 小怪（史莱姆、蘑菇、狼） | 32×32 | ×4 = 128px | 细节少，动作利落 |
| 精英 / 中型怪（忍者、鬼面） | 48×48 | ×4 = 192px | 可加 1~2 个装饰色 |
| Boss（石像、机器人、龙） | 64×64 | ×4 = 256px | 可再加 16px 外发光层 |
| 玩家角色（未来） | 48×48 | ×4 = 192px | 与中型怪同级 |

- 每帧统一尺寸；透明背景；同一张 sheet 内所有帧使用同一调色板。
- 帧数（本节唯一权威）：待机 4~6 帧循环；受击 3~4 帧播一次；攻击 4~6 帧播一次；死亡 4~6 帧（预留）；施法/技能（预留行）。
- 命名：`<角色id>_sprite.png`（如 `slime_sprite.png`），与数据 `art` / 未来 `sprite` 字段对应。

### 2.2 调色板（暗色奇幻像素）

- 单图 ≤ 12 色 + 透明，整体低饱和、暗底、少量高饱和点缀（眼、能量、火焰）。
- 阴影用同色相深色而不是黑色；高光用同色相亮色而不是纯白。
- 每张 sheet 附一个「主色」字段建议：`<角色id>_sprite.meta.json`（可选，含主色、动作行数、每行帧数、帧时长），供帧动画播放器读取，不用硬编码。

### 2.3 行布局（素材格式）

- 第 1 行：待机（循环）
- 第 2 行：受击（播一次后切回待机）
- 第 3 行起：攻击 / 死亡 / 施法（预留）

播放状态机与编辑器预览见 `docs/animation-guide.md` §7。

### 2.4 AI 出图 Prompt 模板（像素）

```text
Pixel art game sprite sheet, dark fantasy style, single [角色描述],
[待机/受击/攻击] animation frames laid out in [N] rows,
each row [M] frames, uniform frame size [W]x[H] px,
transparent background, limited palette (max 12 colors),
low saturation with one accent color, consistent outline,
no text, no watermark, smooth motion between frames
```

卡图（卡牌窗口内立绘）模板：

```text
Pixel art illustration, dark fantasy, [卡牌主题描述],
[W]x[H] px, transparent or dark vignette background,
limited palette matching game palette, readable silhouette at small size
```

出图产物先放 `assets/packs/` 验收，确认后整理到 `assets/` 对应分类目录。

## 3. 卡牌：3D 材质卡体

### 3.1 卡体结构（从上到下）

```text
┌─────────────────────────────┐
│  ┌──┐                       │  ← 左上：费用宝石（金属圆片）
│  │1 │  卡牌名称              │  ← 名称条（描金文字）
│  └──┘  类型                 │  ← 攻击 / 技能 / 能力
│                             │
│  ┌───────────────────────┐  │
│  │  像素卡图窗口          │  │  ← 中央卡图：像素立绘/特效，带内凹画框
│  └───────────────────────┘  │
│                             │
│  卡牌描述（效果文本）        │  ← 材质化底板上的文字
│  [消耗] [虚无] [打出后移除]  │  ← 标签行
└─────────────────────────────┘  ← 底部厚度边（3D 感）
```

### 3.2 材质实现要点（CSS）

卡体 3D 感来自四层叠加，全部用 CSS 实现：

1. **底板**：`linear-gradient` 模拟材质底色（布纹用细噪点，金属用高对比渐变）。
2. **边框**：`border + box-shadow` 双层——外圈描边 + 内圈高光线（`inset`），形成倒角。
3. **厚度**：`::after` 伪元素做卡片侧边（深色渐变条），配合轻微 `perspective` 悬停倾斜，产生厚度错觉。
4. **高光**：`::before` 伪元素做顶部镜面高光（半透明白色径向渐变），随悬停/选中移动。
5. **箔面旋转**：`conic-gradient` 放在圆角裁剪容器内旋转（`overflow: hidden`），
   渐变绕卡面中心转，角部不会甩出卡面。

附加：`image-rendering: pixelated` 只作用于卡图窗口内的像素素材，卡体本身不用。

### 3.3 3D 交互（跟随鼠标）

- 卡牌悬停时沿**双轴**倾斜：`rotateX`（上下，由鼠标纵向位置驱动）+ `rotateY`（左右，由鼠标横向位置驱动），
  最大约 10°~12°，并用 CSS `transition` 平滑。
- 镜面高光中心（`--lx` / `--ly`）与倾斜同步移动，形成"光随鼠标走"的材质感。
- 悬停伴随轻微上浮（约 -8px）；鼠标移出后回正。

### 3.4 类型色（沿用现有语义，换矿物颜料色）

| 类型 | 色值 | 观感 |
| --- | --- | --- |
| 攻击 | `#c0553f` 赭红 | 铁锈/血 |
| 技能 | `#4f7fc4` 靛蓝 | 冷钢 |
| 能力 | `#8a5fc0` 暗紫 | 秘法 |

### 3.5 稀有度材质层（核心：为金卡/闪卡预留）

| 稀有度 | 材质 | 视觉特征 | 状态 |
| --- | --- | --- | --- |
| 起始/普通 | 粗布 + 皮革描边 | 哑光、低饱和、窄边框 | 本期实现 |
| 罕见 | 银灰金属描边 | 冷色金属线 + 轻微高光 | 本期实现 |
| 稀有 | 蓝紫合金 + 微光 | 边框发光、卡体微辉光 | 本期实现 |
| **金卡（未来）** | 金箔金属 | 金色渐变 + 浮雕文字 + 强镜面高光 | 材质层本期预留 |
| **闪卡（未来）** | 动态箔面 | 彩虹 `conic-gradient` 低速旋转 + 高光扫过动画 | 材质层本期预留 |

金卡/闪卡的材质以「CSS class 切换」实现（如 `.card.gold`、`.card.foil`），与稀有度字段解耦——稀有度决定掉落，材质决定观感。这样未来新增"金卡版本"不需要改卡面结构。

> （`backdrop-filter` 模糊 + 半透明白渐变 + 高光带，颜色取类型色 `--card-accent`，
> 与 `docs/art-card-studio.html` 的 `.mat-glass` 同款语言）。

## 4. UI：材质系统

全局沿用现有暗色蓝灰基底，但所有"面板"从平面色块升级为材质化：

| 组件 | 材质 | 要点 |
| --- | --- | --- |
| 主背景 | 深空墨色 + 微光晕 | `#0d1017` 起底，径向渐变营造纵深 |
| 面板（战斗/菜单/商店） | 皮革 | 深棕黑底 + 细描边 + 内阴影，四角小圆角 |
| 按钮 | 金属（主）/ 玻璃（次） | 顶部高光线 + 按下位移；危险按钮用锈红金属 |
| 血条 / 格挡 | 宝石槽 | 深色凹槽 + 内发光填充，宽度变化带平滑过渡 |
| 能量 | 金属圆珠 | 满格金色发光，空槽暗灰凹刻 |
| 地图节点 | 石板 | 浮雕边框，当前节点金边发光 |
| 弹窗/叠层 | 磨砂玻璃 | `backdrop-filter` 轻微模糊 + 半透明黑 |

与卡牌同一套 token（见第 7 节），保证 UI 与卡牌材质语言一致。

## 5. 背景：3D 纵深分层

背景走**3D 质感分层**（不是像素），让像素角色站进去产生 HD-2D 反差：

```text
远景层   大气雾 / 山体剪影 / 壁画     低对比、冷色、模糊感
中景层   战斗场景（地面/废墟/祭坛）    主要明暗对比，角色站立面
近景层   前景暗角 / 站位高光          压暗四角，聚焦战场
```

- 三层用 CSS 分层叠放，预留视差（`transform: translateX/Y` 按场景滚动比例）。
- 楼层主题：**第 1 层**冷灰石质地牢（雾蓝）、**第 2 层**暗绿沼泽（苔绿）、**第 3 层**红黑熔岩（炽红）。
- 主菜单/地图/商店共用同一套氛围，只换局部装饰。

```text
assets/
├── cards/        卡牌像素卡图（<卡牌id>.png）
├── enemies/      怪物 Sprite Sheet（<角色id>_sprite.png）
├── relics/       遗物图标
├── events/       事件插图
├── ui/           UI 贴图（面板纹理/材质贴图）
├── backgrounds/  背景分层素材
└── packs/        AI 出图原始包/调色板/meta 文件（确认后转正）
```

引用约定：数据字段 `art` / `sprite` 使用相对路径，如 `assets/enemies/slime_sprite.png`。

演示页约定：`docs/art-<对象>-material.html`（卡牌 / 怪物 / 背景各一页），脚本顶部有素材配置区：
`kind: "pixel"` 用内置占位像素画；`kind: "image"` 引用 `assets/` 实际素材，方便随时替换测试。

## 11. 卡面结构定稿（v4，2026-08-14）

以 `docs/art-card-studio.html` 为准，卡面自上而下：

1. 卡面底版 `.face`：类型色边框渐变（攻击红 / 技能蓝 / 能力紫）
2. 画窗外框 `.art-frame`：银/金色渐变边框环，随类型形状裁剪
3. 画窗图片层 `.art-window`：与边框层**同心同形状**裁剪，支持拖拽 / 缩放 / 滚轮
4. 费用球 `.cost`（左上）+ 类型宝石 `.type-gem`（右上），压住画角
5. 卡名 `.name`：顶部居中；异画方案下浮在画上
6. 稀有度宝石 `.rarity-gem`：嵌入描述面板顶部（普通 24px / 异画 22px）
7. 描述面板 `.desc`：固定高度、浅色半透明、横纵居中、溢出隐藏
8. 底部信息条 `.info-strip`：编号 + 类型（+ 稀有度）

### 11.1 七套方案与类型形状

- 普通卡 A 经典大画窗 / B 全宽无框画 / C 纵向三段 / D 极简留白；
  异画卡 E 满版悬浮 UI / F 满版极简角标 / G 满版金框
- 类型形状：攻击 = 圆角矩形；技能 = 五边形；能力 = 椭圆（`clip-path` 作用于
  `.art-frame` 与 `.art-window` 两层，**同心裁剪**保证边框沿形状环绕）
- 数据模型预留：`CardData.altArt?: boolean`、`shape?: "rect" | "pentagon" | "ellipse"`

### 11.2 全息闪卡与浮雕（2026-08-14）

> 唯一权威：`docs/emboss.md`（卡牌表面工艺方案：浮雕三路线 / 全息叠层 / 产品决策 / 踩坑 / 性能）。
> 交互演示：`docs/art-card-studio.html`（卡牌美术工作台：材质 / 动画 / 布局 一体）。

决策摘要（细节与踩坑见 emboss.md §6）：

- 3D 只做"整卡旋转 + 图案随鼠标视角"，膜层贴死卡面；卡图不做每帧独立位移、不加 `will-change`
- 手牌常态只开 bevel / gold（纯阴影零滤镜）；悬停 / 大图才开 art / grain（SVG 滤镜）
- 异画卡亮底全息混合用 `overlay`，普通卡用 `color-dodge`
- 文字保持平面不参与浮雕
