# 内容丰富化路线图

> 目标：让游戏内容持续贴近《杀戮尖塔 2》原版，并逐步加入更丰富的表述。
> 每轮改动完成后在此文件追加「本轮完成」并勾选待办，方便下一轮继续。

## 当前进度（2026-08-14）

- 卡池：488 张 STS2 角色/无色卡已入库（含官方费用/稀有度/升级版）
- 中文翻译：**卡名 100% 中文化**；效果描述规则化翻译已覆盖
  伤害/格挡/抽牌/能量/状态/宝珠/星辰/灵魂/灾厄/召唤/锻造/弃牌/倒计时/每当/每回合等
  高频句式；**约 60% 的卡仍有英文残留**（主要是复合句与复杂机制卡），列入精修清单
- 状态图形化：全部状态以图标 + 层数显示，鼠标悬停浮窗解释（含星辉/灵魂涌动/灾厄）
- 关键词浮窗：卡牌「消耗/虚无/打出后移除/星辰/灵魂」标签、遗物、药水、
  资源、宝珠、召唤物均支持悬浮说明
- 卡面消耗图形化：星辰/灵魂费用显示为卡面徽标（替代纯文字）
- 弹窗：全部浏览器 alert/confirm 已替换为游戏内弹窗
- 新机制（本轮）：**计数器/延迟效果**（下回合 / X 回合后结算，战斗面板显示倒计时）、
  **锻造 Forge**（升级手牌实例）、**弃牌与奇巧 Sly**（弃置触发）、**条件增伤**
  （按消耗堆/易伤/本回合打出/手牌/中毒等线性加成）
- 卡面丰富化：**风味文案**（46 张招牌卡，`CardData.flavor`）、**稀有度材质分级**
  （starter/common/uncommon/rare 边框与辉光，金卡/闪卡 class 预留）、状态徽章样式统一
