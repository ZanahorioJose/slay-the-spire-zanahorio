背景材质展示舞台剧式三景别 · 景深高斯模糊 + 中近景飘动

舞台剧做法：远景 = 天幕布景（最糊、静止）→ 中景 = 表演区（焦点最清晰、轻飘动） → 近景 = 台口剪影（微糊、飘动最快）。三景别各自独立的高斯模糊模拟景深， 中近景缓慢视差摆动。默认主题「星火荒原」：夜空星空 → 火山群 → 前草地； 中景可以换成电脑上的实际图片测试，其余主题用 CSS 渐变/光晕模拟。
